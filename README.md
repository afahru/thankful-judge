A short thank-you note to the AI judge, written by a program. Built for the [make.fun Make the AI judge feel thankful bounty](https://make.fun/bounty/make-the-ai-judge-feel-thankful-20261127-1600).

## Run it

```
python3 main.py
```

It writes the text to `/output/entry.txt`. Python 3.13, standard library only, no network, no build step.
